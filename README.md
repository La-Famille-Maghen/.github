# .github — Fichiers par défaut de l'organisation La Famille Maghen

Ce dépôt spécial GitHub sert deux fonctions distinctes :

- [`profile/README.md`](profile/README.md) — la **page de profil publique** de l'organisation, affichée sur [github.com/La-Famille-Maghen](https://github.com/La-Famille-Maghen). C'est le seul chemin que GitHub traite spécialement.
- Un fichier placé à la **racine** de ce dépôt (`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, etc.) devient le **fichier de santé communautaire par défaut** pour tout dépôt de l'organisation qui n'a pas sa propre version de ce fichier.

**État actuel : aucun fichier de santé communautaire par défaut n'est défini ici.** Chaque dépôt porte ses propres fichiers, spécifiques à son contexte — par exemple [`e-photo-id-express-client-test-releases`](https://github.com/La-Famille-Maghen/e-photo-id-express-client-test-releases), qui a son propre `CONTRIBUTING.md`/`SECURITY.md`/`CODE_OF_CONDUCT.md` centrés sur le programme testeurs.
